## ✨ About the Project

**Here Saudi (هنا السعودية)** is a Django-powered website created to introduce visitors to the Kingdom of Saudi Arabia through an immersive, modern, and responsive digital experience.

The project brings together the Kingdom's story, destinations, cultural experiences, and sporting ambitions in one place. Each section has its own visual identity while maintaining a consistent navigation experience.

The interface is primarily Arabic and is designed around a premium visual direction, with dedicated **dark and light modes**.

## 🧭 Explore the Website

The website includes the following pages and experiences:

| Page | Description | Route |
|---|---|---|
| **Home — الرئيسية** | Main landing page and entry point to discover the Kingdom. | `/` |
| **The Kingdom & Its History — المملكة وتاريخها** | A journey through the Kingdom's roots, history, and development. | `/kingdom/` |
| **Tourism & Entertainment — السياحة والترفيه** | An introduction to Saudi tourism, destinations, entertainment, and experiences. | `/tourism-entertainment/` |
| **Sports — الرياضة** | Saudi Arabia's sporting journey and major upcoming events, including the 2027 AFC Asian Cup and 2034 FIFA World Cup. | `/sports/` |
| **Culture & Knowledge — الثقافة والمعرفة** | Cultural experiences, knowledge, arts, and the King Abdulaziz Center for World Culture (Ithra). | `/culture/` |
| **The Red Sea — البحر الأحمر** | A destination experience highlighting the Red Sea. | `/red-sea/` |
| **AlUla — العُلا** | Discover AlUla's landscapes, heritage, and experiences. | `/alula/` |
| **Diriyah — الدرعية** | Explore the historical home of the First Saudi State. | `/diriyah/` |
| **Al-Ahsa — الأحساء** | Discover Al-Ahsa's natural, cultural, and heritage identity. | `/al-ahsa/` |

## 🎨 Highlights

- **Dark & Light Mode:** Switch between two display themes.
- **Responsive Layout:** Designed to adapt to desktop, tablet, and mobile screens.
- **Shared Layout:** Reusable Django template inheritance for consistent navigation and footer.
- **Destination Experiences:** Dedicated pages for the Red Sea, AlUla, Diriyah, and Al-Ahsa.
- **Media-Rich Sections:** Image galleries and video-led visual experiences.
- **Distinct Page Identities:** Individual color palettes and visual treatments for different sections.
- **Arabic-First Experience:** Arabic content and right-to-left page presentation.

## 🚀 Run Locally

### Prerequisites

- Python 3.12 or newer
- pip
- Git

### 1. Clone the repository

```bash
git clone https://github.com/iimustafa/UNIT-PROJECT-2.git
cd UNIT-PROJECT-2
```

### 2. Create and activate a virtual environment

**macOS / Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Install Django

```bash
pip install Django==6.1.3
```

### 4. Move into the Django project directory

```bash
cd SaudiProject
```

### 5. Apply migrations

```bash
python manage.py migrate
```

### 6. Start the development server

```bash
python manage.py runserver
```

Open **http://127.0.0.1:8000/** in your browser.

## 🎬 Media Assets

Large video files are intentionally excluded from Git tracking to keep the repository lightweight.

If you run the project locally and a page references a video that is not included in the repository:

1. Place the original video in its corresponding path under `SaudiApp/static/SaudiApp/videos/`, or
2. Host the video on a media/CDN provider and update the relevant video source in the template.

Image and screenshot assets used in the README should be committed under the `screenshots/` directory.
